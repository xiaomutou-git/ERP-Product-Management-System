## 1. 设计原则与整体风格定位

### 1.1 风格定位

**清爽科技蓝 · 专业 B 端工具型界面**。整体观感：浅灰蓝底色承载白色卡片，青蓝色（Cyan）作为唯一品牌色贯穿交互反馈，信息密度适中，无装饰性噪音。定性为"数据工具"而非"营销页面"——一切视觉服务于快速读取与快速操作。

### 1.2 设计红线（强制，验收依据）

| 编号 | 红线 | 实现口径 |
| --- | --- | --- |
| R1 | 配色基调：清爽科技蓝 | 主色 `#06B6D4`，悬停 `#0891B2`，聚焦/激活 `#0E7490`；全局页面底色 `#F1F5F9`（浅灰蓝，**禁止**纯白大面积背景，**禁止** `#F5F7FA` 等中性灰）；**禁止深色背景**（侧栏、顶栏均为浅色） |
| R2 | 动画克制 | 只允许 150–250ms、ease-out 缓动的微动画；**禁止**滚动视差、3D 翻转、弹跳、粒子、无限循环装饰动画；页面切换必须有轻量入场动画（淡入 + 8px 上移，220ms） |
| R3 | 圆角克制 | 按钮等控件圆角 8px，禁止 999px 胶囊按钮、禁止超大圆角卡片（>16px） |
| R4 | 多设备自适应 | 桌面 ≥1280px 为主战场，兼顾 1024 / 768 / 375 三档；表格在窄屏允许容器内横向滚动 |
| R5 | 禁止表情包 | UI 中不出现任何 emoji 表情图片/表情包素材；状态一律用色点、标签、线性图标表达 |
| R6 | 浏览器缩放稳定 | 布局骨架使用 flex / grid / 百分比 / minmax；间距与控件尺寸以 rem 落地（基准 1rem = 16px，本文所有 px 标注 ÷16 换算），禁止外层容器写死总宽 |

### 1.3 五条设计原则

1. **一屏一事**：每个页面只解决一个主任务（查列表 / 填单据 / 看统计），筛选区、数据区、操作区分层明确，不加无关模块。
2. **数据优先**：金额、数量等关键数字统一使用等宽数字（`font-variant-numeric: tabular-nums`），右对齐；状态一律"彩色标签"而非纯文字。
3. **权限可见**：无权限的操作按钮直接不渲染（非置灰），与 PRD 2.2 权限矩阵一一对应；viewer 角色看不到任何"新增/编辑/删除"按钮。
4. **危险隔离**：删除、停用、取消采购单、重置密码等破坏性操作一律红色 + 二次确认弹窗，确认按钮为红色实心。
5. **反馈即时**：所有写操作必须有 loading（按钮内旋转指示）与结果 toast；列表请求期间表格显示骨架或 loading 遮罩，禁止白屏等待。

### 1.4 动效规范总表

| 场景 | 属性 | 时长 | 缓动 | 备注 |
| --- | --- | --- | --- | --- |
| 按钮/链接/输入框 hover | color / background / border | 150ms | ease-out | |
| 输入框聚焦环 | box-shadow | 150ms | ease-out | |
| 页面切换入场 | opacity 0→1 + translateY 8px→0 | 220ms | ease-out | 作用于路由容器，见 3.5 |
| 弹窗出现 | opacity + scale 0.96→1 | 200ms | ease-out | 关闭 150ms |
| 抽屉滑出 | transform translateX 100%→0 | 240ms | ease-out | |
| Toast 进入 | opacity + translateY -8px→0 | 200ms | ease-out | 自动关闭 3000ms |
| 侧栏折叠/展开 | width | 200ms | ease-out | |
| Loading spinner 旋转 | transform rotate | 1000ms | linear infinite | **功能性指示，允许**；装饰性无限循环一律禁止 |
| 骨架屏 | 静态色块，**不做** shimmer 扫光 | — | — | 遵守 PRD"禁止无限循环动画" |

| `md` | 1024 – 1279px | 平板横/小笔电：侧栏默认折叠为 64px 图标栏、看板 2x2、表单两列 |
| `lg` | ≥ 1280px | **桌面标准**：侧栏展开 240px、看板 4 列、表单两列 |

```scss
  "primary": ("base": #06B6D4),
);
@use "element-plus/theme-chalk/src/index.scss" as * with (
  $colors: $colors,
  $border-radius: ("base": 8px, "small": 6px, "round": 999px),
  $font-size: ("base": 14px, "small": 13px, "extra-small": 12px),
  $border-color: ("base": #E2E8F0, "light": #E2E8F0, "lighter": #F1F5F9)
);
```

同时覆写运行时变量：`--el-color-primary: #06B6D4; --el-color-primary-light-3: #0891B2; --el-color-primary-dark-2: #0E7490; --el-color-primary-light-9: #ECFEFF; --el-text-color-primary: #1E293B; --el-text-color-regular: #475569; --el-text-color-secondary: #64748B; --el-border-color: #E2E8F0; --el-fill-color-light: #F8FAFC;`。

### 3.5 页面切换动画（R2 强制）

路由容器统一实现，所有页面复用：

```css
/* 页面入场：淡入 + 8px 上移，220ms ease-out（R2 红线，全局唯一页面级动效） */
.page-enter-active {
  animation: pageIn 220ms ease-out;
```

## 7. 可用性与可访问性要求

### 7.1 对比度（正文 AA ≥ 4.5:1，大字/加粗 ≥ 3:1）

| 前景 / 背景 | 约对比度 | 结论 |
| --- | --- | --- |
| `#1E293B` / `#FFFFFF` | ≈ 15.0 : 1 | 通过（一级文字） |
| `#475569` / `#FFFFFF` | ≈ 7.6 : 1 | 通过（二级文字/表头） |
| `#64748B` / `#FFFFFF` | ≈ 4.8 : 1 | 通过（三级文字 ≥14px） |
| `#94A3B8` / `#FFFFFF` | ≈ 2.9 : 1 | 仅限占位符/禁用态（豁免项） |
| `#FFFFFF` / `#06B6D4` | ≈ 2.4 : 1 | 主按钮文字需 500+ 字重；如验收方要求严格 AA，主按钮底色可整体切换为 `#0E7490`（≈ 5.2 : 1），CSS 变量一键切换，其余规范不变 |
| `#B45309` / `#FEF3C7` | ≈ 4.9 : 1 | 通过（低库存 Tag） |
| `#047857` / `#D1FAE5` | ≈ 4.9 : 1 | 通过（成功 Tag） |
| `#B91C1C` / `#FEE2E2` | ≈ 5.3 : 1 | 通过（危险 Tag） |
| `#1D4ED8` / `#DBEAFE` | ≈ 6.3 : 1 | 通过（信息 Tag） |

### 7.2 键盘可达

1. 全站 Tab 顺序：遵循 DOM 顺序（筛选区 → 表格 → 分页 → 页头按钮），不得用 CSS 打乱视觉与焦点顺序。
2. 弹窗：打开时焦点落入弹窗首个可交互元素，Tab 循环锁定于弹窗内（焦点陷阱），Esc 关闭，关闭后焦点归还触发元素。
3. 表单：Enter 在单行输入框内触发提交；错误字段在提交后自动 focus 到第一个错误项。
4. 表格操作列与按钮均为原生可聚焦元素；下拉/抽屉支持方向键选择、Enter 确认（Element Plus 默认行为保留）。
5. 侧栏折叠按钮、汉堡按钮可 Tab 聚焦，Enter 触发。

### 7.3 焦点样式（全局强制）

```css
/* 键盘焦点环：仅键盘导航出现，鼠标点击不出现；颜色取主色亮阶保证在白/灰底可见 */
:focus { outline: none; }
:focus-visible {
  outline: 2px solid #06B6D4;
  outline-offset: 2px;
  border-radius: 8px; /* 与宿主控件圆角一致 */
}
/* 输入类控件焦点改用发光环（见 4.2），二者不叠加 */
```

### 7.4 其他要求

1. 语义化与读屏：图标按钮必须 `aria-label`（如"删除商品 TEST-001"）；状态 Tag 由文本承载语义（不依赖颜色单通道）；表格使用 `role="table"` 语义（Element Plus 默认）；错误 toast 容器 `aria-live="polite"`，校验错误 `aria-invalid="true"`。
2. 动效降级：`@media (prefers-reduced-motion: reduce)` 下关闭页面入场与过渡（见 3.5）。
3. 缩放稳定（R6）：`html { font-size: 16px; }` 固定基准，组件尺寸标注 px、落地换算 rem（px ÷ 16）；页面骨架 flex/grid，卡片宽度百分比或 `minmax`，唯一允许出现横向滚动的是表格容器。
4. 触控目标：≤768px 下所有可点元素命中区 ≥ 40x40px（视觉尺寸不变时用透明 padding 扩展）。
